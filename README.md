# Godfrey Alao — Online CV

A responsive, static online CV for GitHub Pages. Built with HTML, CSS, and JavaScript; no build tools or paid hosting required.

## Files
- `index.html` — CV content
- `style.css` — responsive dark navy/cyan design and print styling
- `script.js` — mobile navigation and print/save-as-PDF button

## Publish using a phone
1. Sign in or create an account at https://github.com.
2. Tap **+** → **New repository**.
3. Name the repository `godfrey-online-cv` (or another name), set it to **Public**, and create it.
4. Open the new repository, choose **Add file** → **Upload files**.
5. Upload `index.html`, `style.css`, and `script.js` from this folder. They must be in the repository root, not inside another folder.
6. Tap **Commit changes**.
7. Open the repository **Settings** → **Pages**.
8. Under **Build and deployment**, select **Deploy from a branch**. Select branch **main** and folder **/(root)**, then save.
9. Wait a few minutes and refresh the Pages screen. GitHub will show your public website URL, typically `https://YOUR-USERNAME.github.io/godfrey-online-cv/`.
10. Open the link on your phone to test it. Send that link to employers.

## Print or save as PDF
Open the published site and tap **Download / Print CV**. In the browser print dialog, choose **Save as PDF** if available. On mobile, the exact option depends on the browser and operating system.

## Before sharing
- Confirm your phone number and email are correct.
- Add your expected graduation date only when confirmed.
- Add project dataset, model, test results, and source-code links only when accurate.
- Never upload passwords, private keys, personal identification numbers, or confidential school data.
- GitHub Pages is public: anyone with the link can view the CV.
